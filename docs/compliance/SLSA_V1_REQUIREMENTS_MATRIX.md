# SLSA v1.0 Level 3 Requirements Audit & Verification Matrix

## Overview
Supply chain Levels for Software Artifacts (**SLSA**) is a security framework from Google and the OpenSSF preventing tampering, improving software integrity, and securing packages and infrastructure.

---

## Detailed Compliance Checklist

| SLSA Requirement | Level | Status | Implementation in this Pipeline | Verification Method |
|---|---|---|---|---|
| **Choose a build platform** | L1 | **PASS** | GitHub Actions hosted runners (`ubuntu-latest`) | CI workflow configuration audit |
| **Generate provenance** | L1 | **PASS** | In-toto SLSA provenance generated automatically via Cosign | Inspection of Rekor transparency log |
| **Hosted build platform** | L2 | **PASS** | Multi-tenant isolated GitHub-hosted runners | Provenance `builder.id` validation |
| **Verified build service** | L2 | **PASS** | GitHub Actions signed OIDC token identity | Fulcio certificate SAN matching repo |
| **Unforgeable provenance** | L2 | **PASS** | Signed using ephemeral keys backed by Fulcio/Rekor | `cosign verify-attestation` |
| **Isolated build environment**| L3 | **PASS** | Fresh virtual machine container spawned per job | Ephemeral runner guarantee |
| **Non-falsifiable provenance**| L3 | **PASS** | Provenance generated directly by build platform, not user | OIDC claims generated by runner |
| **Hardened build dependencies**| L3 | **PASS** | Pinned dependencies with SHA256 verification | `requirements.txt` hash checking |
| **Hermetic builds (target)** | L3 | **PASS** | Network egress restricted during compile/test step | Container firewall sandbox |

---

## Provenance Inspection Command
```bash
cosign verify-attestation \
  --type https://slsa.dev/provenance/v0.2 \
  --certificate-identity-regexp=".*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  ghcr.io/ravishkarathnayaka/enterprise-supply-chain-app@sha256:...
```
