# NIST IR 8397: Guidelines on Minimum Standards for Developer Verification

## 1. Purpose
NIST Interagency Report 8397 defines minimum standards for developer verification of software per Executive Order 14028.

---

## 2. Verification Controls
- **Threat Modeling**: Formal STRIDE threat modeling performed on architecture.
- **Automated Code Scanning**: Static application security testing (Semgrep) integrated into CI.
- **Dependency Analysis**: Automated Software Bill of Materials (SBOM) and vulnerability identification.
