# NIST SP 800-161 Rev 1: Cybersecurity Supply Chain Risk Management

## 1. Objective
Provides guidance on identifying, assessing, and mitigating supply chain risks throughout software procurement and development.

---

## 2. Implementation Framework
- **C-SCRM Control 1: Transparency**: Continuous SBOM production and cryptographic provenance binding.
- **C-SCRM Control 2: Integrity Verification**: Enforced cryptographic image signatures verified before deployment.
- **C-SCRM Control 3: Continuous Monitoring**: Automated scanning of deployed workloads and dependency registries.
