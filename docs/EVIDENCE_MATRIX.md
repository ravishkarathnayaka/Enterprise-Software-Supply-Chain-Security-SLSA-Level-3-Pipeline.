## 2. External Audit Verification Commands
To independently verify this pipeline from any external terminal:
```bash
# 1. Verify Image Signature
cosign verify \
  --certificate-identity-regexp="https://github.com/ravishkarathnayaka/.*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  ghcr.io/ravishkarathnayaka/enterprise-supply-chain-app@sha256:...

# 2. Verify SLSA Level 3 Provenance
cosign verify-attestation \
  --type="https://slsa.dev/provenance/v0.2" \
  --certificate-identity-regexp="https://github.com/ravishkarathnayaka/.*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  ghcr.io/ravishkarathnayaka/enterprise-supply-chain-app@sha256:...
```
